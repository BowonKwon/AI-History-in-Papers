Ch. 7 Agents 2022–

Agents (2022– )

Models use tools and act.

Key point

  • ReAct (6 October 2022) had a language model interleave reasoning traces and actions so that it could gather information from external sources such as a Wikipedia API. Twenty of the chapter's 22 papers have no references in OpenAlex, so every lineage line here was drawn from the papers' own reference lists.
  • In 2023 the original texts of tools (Toolformer, February), reflection (Reflexion, March), society (Generative Agents, April), search (Tree of Thoughts, May), skill accumulation (Voyager, May), multi-agent collaboration (MetaGPT, August) and memory (MemGPT, October) appeared within one year.
  • Evaluation and security followed in the same year: SWE-bench (October), WebArena (July), AgentBench (August) and GAIA (November) defined tasks, and indirect prompt injection (February) showed that instructions planted in retrieved data can steer an agent. "AI Agents That Matter" (2024) questioned accuracy comparisons that ignore cost.

This chapter is divided into six strands so that each can later grow into a chapter of its own. Each strand has two or three original texts, all between December 2021 and January 2025.

Language models that act

WebGPT (Nakano et al.) (17 December 2021) fine-tuned GPT-3 with human demonstrations and feedback to search and browse in a text-based environment and answer with references. On the robot side, SayCan (Ahn et al.) (4 April 2022) multiplied a language model's scores for skills by the value functions of pretrained robot skills to choose actions that are "feasible and contextually appropriate", and Inner Monologue (Huang et al.) (12 July 2022) added a closed loop that returns environment feedback, success detection and scene description, as text. Then ReAct (Yao et al.) (6 October 2022; ICLR 2023) inserted actions into the chain of thought of chapter 6: generating reasoning traces and task-specific actions in an interleaved way lets the actions gather information from external sources such as a Wikipedia API. It was evaluated on HotpotQA, Fever, ALFWorld and WebShop; twelve of the chapter's other 21 papers cite it in their reference lists.

Tools

Toolformer (Schick et al.) (9 February 2023) trained a language model in a self-supervised way, from a few demonstrations per API, to insert calls to a calculator, search engine, translator and calendar into text. HuggingGPT (Shen et al.) (30 March 2023) had ChatGPT plan tasks from a request and select and run Hugging Face models by their descriptions. The difference between the two later becomes the fork between learning tools by training and choosing tools by prompting.

Reflection, search, memory

Reflexion (Shinn et al.) (20 March 2023) has the agent reflect verbally on task feedback, keep the reflections in an episodic memory and use them in later trials without changing weights; it reported 91% pass@1 on HumanEval against 80% for GPT-4. Tree of Thoughts (Yao et al.) (17 May 2023) searches, by BFS or DFS, a tree of intermediate "thoughts" the model generates and evaluates itself, raising the Game of 24 from 4% with chain of thought to 74%. MemGPT (Packer et al.) (12 October 2023) proposed virtual context management, modeled on operating-system virtual memory, moving information between the context window and external storage tiers. All three add capability through structures outside the model: a memory buffer, a search tree, storage tiers.

Society and division of labor

Generative Agents (Park et al.) (7 April 2023; UIST '23) placed 25 agents in a Sims-like town with an architecture that stores experience in natural language, synthesizes it into reflections and retrieves it for planning. Voyager (Wang et al.) (25 May 2023) is a GPT-4 agent in Minecraft that builds an automatic curriculum and a library of executable code skills. MetaGPT (Hong et al.) (1 August 2023; ICLR 2024) encoded standard operating procedures as prompt sequences and arranged role-playing agents in an assembly line.

Evaluation

Without defined tasks, agents cannot be compared. WebArena (Zhou et al.) (25 July 2023) built self-hosted working websites in four domains and scored 812 tasks by functional correctness (best GPT-4 agent 14.41%, humans 78.24%). AgentBench (Liu et al.) (7 August 2023) tested 29 models in 8 environments; SWE-bench (Jimenez et al.) (10 October 2023) turned 2,294 GitHub issues into codebase-editing tasks, of which the best model of the time resolved 1.96%. GAIA (Mialon et al.) (21 November 2023) is 466 questions on which humans scored 92% and GPT-4 with plugins 15%. In 2024, OSWorld (11 April) added 369 tasks in real operating-system environments (humans 72.36%, best model 12.24%); SWE-agent (Yang et al.) (6 May) reached 12.47% on SWE-bench through agent-computer interface design; τ-bench (Yao et al.) (17 June) added customer-service tasks with a simulated user and a policy document, and the consistency metric pass^k. Kapoor et al., "AI Agents That Matter" (1 July 2024) pointed to accuracy comparisons that ignore cost and to reproducibility problems, and proposed accuracy–cost Pareto curves.

Security and training for reasoning

Greshake et al., "Not What You've Signed Up For" (23 February 2023) described indirect prompt injection, in which instructions planted in data the agent retrieves steer the model remotely, and demonstrated it against Bing Chat among others. The observation that everything an agent reads is an attack surface is part of this site's own working rules. The chapter's last point, DeepSeek-R1 (22 January 2025; Nature, September 2025), reported that reasoning ability can be incentivized by reinforcement learning with rule-based rewards alone, without supervised fine-tuning. The reasoning that chapter 6 elicited by prompting moves here into the training objective, and the scope of version 1.0 ends here.

What was and was not checked

All 22 papers were read in their arXiv versions, several of them revisions long after the conference (AgentBench v3 from October 2025; MetaGPT v7 and SWE-bench v3 from November 2024); quotations and reference lists are those of the version read, which the card names. Peer-reviewed publication could not be confirmed for MemGPT and τ-bench. Among the candidates, the survey papers of 2023 onward and public repository documents (the MCP specification, engineering blog posts) are not original papers and were given no point.

Tree of Thoughts: Deliberate Problem Solving with Large Language Models

Shunyu Yao, Dian Yu, Jeffrey Zhao, Izhak Shafran J, Thomas L. Griffiths, Yuan Cao et al. · First public 2023-05-17 (arXiv v1) · Venue: arXiv:2305.10601 [cs.CL]; published in Advances in Neural Information Processing Systems 36 (NeurIPS 2023) · Pages 14 pp. (arXiv v2) · Citations (OpenAlex) 1,176 (checked 2026-11-03)

What changed. Introduced Tree of Thoughts (ToT), an inference framework that generalizes chain-of-thought prompting by keeping a tree of intermediate "thoughts" that the language model generates and self-evaluates, combined with search algorithms (BFS, DFS) that allow lookahead and backtracking. arXiv · peer-reviewed venue not verified: OpenReview API searches (title, 'Tool-Agent-User Interaction') returned no τ-bench record

In this work, we introduce τ-bench (short for Tool-Agent-User Interaction Benchmark) to measure an agent’s ability to interact with (simulated) human users and programmatic APIs while following domain-specific policies in a consistent manner.p. 1 (arXiv v1)

What changed. Introduced τ-bench, a benchmark in which a language agent with domain-specific API tools and a policy document converses with an LM-simulated user in two customer-service domains (τ-retail, τ-airline), scored by comparing the final database state with an annotated goal state. Also proposed the pass^k metric for consistency across k trials; gpt-4o function-calling agents succeeded on under 50% of tasks, with pass^8 below 25% in retail.

AI Agents That Matter

Sayash Kapoor, Benedikt Stroebl, Zachary S. Siegel, Nitya Nadgir, Arvind Narayanan · First public 2024-07-01 (arXiv v1) · Venue: arXiv:2407.01502 [cs.LG]; published in Transactions on Machine Learning Research (TMLR), 2025 · Pages 33 pp. (arXiv v1) · Citations (OpenAlex) 13 (checked 2026-11-03)

arXiv · title page dated 'July 2, 2024'; TMLR 2025 (OpenReview forum Zy4uFzMviZ, venue 'Accepted by TMLR', publication timestamp 2025-06-13)

The overarching goal of our work is to stimulate the development of agents that are useful in the real world and not just accurate on benchmarks.p. 2 (arXiv v1)

What changed. Analyzed agent benchmarks and evaluation practices and argued that agent evaluations should be cost-controlled, using accuracy-versus-cost Pareto curves and simple baseline agents that match complex agents on HumanEval at lower cost, plus a joint accuracy-cost optimization built on DSPy. Also separated model-developer from downstream-developer benchmarking needs, proposed hold-out requirements by level of agent generality, and documented reproducibility problems in WebArena and HumanEval evaluations.
